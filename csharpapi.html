Important: Continue your previous API project rather than starting a new project. Our guided example uses NFL teams; you may adapt the concepts to your own existing project.

Part 3: Guided Lab — Extend the NFL Teams API

Step 1: Open Your Existing Project

Open your existing ASP.NET Core project in Visual Studio Code. In the integrated terminal, execute:

dotnet restore
dotnet run

Confirm the server starts and note the localhost URL displayed in the terminal. Keep this terminal running while testing.

Step 2: Define a Model

Create Models/Team.cs (or adapt your existing model). If your project's namespace differs, update the namespace accordingly.

namespace NFLTeamsApi.Models
{
    public class Team
    {
        public int Id { get; set; }
        public string Name { get; set; } = "";
        public string City { get; set; } = "";
        public int Wins { get; set; }
        public int Losses { get; set; }
    }
}

Step 3: Add CRUD Endpoints

For a Minimal API project, use the following as a reference for your Program.cs. If your previous project used controllers, implement the equivalent endpoints in your existing controller instead of replacing its architecture.

using NFLTeamsApi.Models;

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

var teams = new List<Team>
{
    new Team { Id = 1, Name = "Steelers", City = "Pittsburgh", Wins = 8, Losses = 3 },
    new Team { Id = 2, Name = "Eagles", City = "Philadelphia", Wins = 9, Losses = 2 }
};

app.MapGet("/api/teams", () => Results.Ok(teams));

app.MapGet("/api/teams/{id:int}", (int id) =>
{
    var team = teams.FirstOrDefault(t => t.Id == id);
    return team is null ? Results.NotFound() : Results.Ok(team);
});

app.MapPost("/api/teams", (Team team) =>
{
    if (string.IsNullOrWhiteSpace(team.Name) ||
        string.IsNullOrWhiteSpace(team.City) ||
        team.Wins < 0 || team.Losses < 0)
        return Results.BadRequest("Invalid team data.");

    team.Id = teams.Count == 0 ? 1 : teams.Max(t => t.Id) + 1;
    teams.Add(team);
    return Results.Created($"/api/teams/{team.Id}", team);
});

app.MapPut("/api/teams/{id:int}", (int id, Team updated) =>
{
    var team = teams.FirstOrDefault(t => t.Id == id);
    if (team is null) return Results.NotFound();

    if (string.IsNullOrWhiteSpace(updated.Name) ||
        string.IsNullOrWhiteSpace(updated.City) ||
        updated.Wins < 0 || updated.Losses < 0)
        return Results.BadRequest("Invalid team data.");

    team.Name = updated.Name;
    team.City = updated.City;
    team.Wins = updated.Wins;
    team.Losses = updated.Losses;
    return Results.Ok(team);
});

app.MapDelete("/api/teams/{id:int}", (int id) =>
{
    var team = teams.FirstOrDefault(t => t.Id == id);
    if (team is null) return Results.NotFound();
    teams.Remove(team);
    return Results.NoContent();
});

app.Run();
Lab note: This example stores data in memory, not in a database. Changes are lost when the application restarts. The team records are sample values, not current NFL standings. Use the localhost port printed by dotnet run for your API requests.

Step 4: Test Your Endpoints

Using Postman or another REST client, submit requests to your running API. For a POST request to /api/teams, choose Body → raw → JSON and enter:

{
  "name": "Ravens",
  "city": "Baltimore",
  "wins": 7,
  "losses": 4
}

Confirm the server returns HTTP 201 and a new ID. Use GET to verify the new team appears. Next, use PUT to change its win/loss values and DELETE to remove it. Finally, request the deleted ID and verify that the API returns 404.

Step 5: Independent Lab Challenges

  1. Search by city: Implement GET /api/teams/city/{city} to return matching teams, ignoring capitalization.
  2. Filter by wins: Implement GET /api/teams/wins/{minimum} to return teams with wins greater than or equal to the requested minimum.

Use LINQ methods such as Where() and ToList(). Test each endpoint with matching and nonmatching values.
