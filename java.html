1.1 Your first Java program

Java programs are organized into classes. The main method is where a basic command-line program begins. System.out.println displays a line of text. Java statements generally end with a semicolon.

Save this file as HelloJava.java. The public class name must match the file name.

public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello, Java students!");
    }
}

Compile with javac HelloJava.java and run with java HelloJava. Expected output: Hello, Java students!

1.2 Variables and data types

A variable stores a value. int stores whole numbers, double stores decimals, boolean stores true/false, and String stores text. Java is statically typed, so each variable has a declared type.

public class VariablesDemo {
    public static void main(String[] args) {
        String student = "Morgan";
        int completedLessons = 2;
        double grade = 94.5;
        boolean passed = grade >= 60;

        System.out.println(student + " completed " + completedLessons + " lessons.");
        System.out.println("Grade: " + grade);
        System.out.println("Passed: " + passed);
    }
}

Try it: Change the grade to 55.0. Predict how passed changes before running the program.

1.3 Conditionals and loops

An if statement runs code when its condition is true. A for loop repeats an action a known number of times.

public class ControlFlowDemo {
    public static void main(String[] args) {
        int score = 82;
        if (score >= 90) {
            System.out.println("A");
        } else if (score >= 80) {
            System.out.println("B");
        } else {
            System.out.println("Keep practicing");
        }

        for (int lesson = 1; lesson <= 3; lesson++) {
            System.out.println("Starting lesson " + lesson);
        }
    }
}

Expected output: B, followed by Starting lesson 1, 2, and 3 on separate lines.

1.4 Methods, classes, and objects

A method groups reusable behavior. A class defines a type of object; an object is an instance of that class. Here a Student stores a name and produces a greeting.

class Student {
    private String name;

    public Student(String name) {
        this.name = name;
    }

    public String greet() {
        return "Welcome, " + name + "!";
    }
}

public class StudentDemo {
    public static void main(String[] args) {
        Student student = new Student("Alex");
        System.out.println(student.greet());
    }
}

Save as StudentDemo.java. The constructor initializes the object's name. private protects the field from direct access outside the class, while public exposes the constructor and greeting method.

public class GradeCalculator {

        double q1 = 90, q2 = 80, q3 = 70;
        double average = (q1 + q2 + q3) / 3;
        String letter;

2.1 Understanding Swing components

JFrame is the application window; JPanel groups components; JLabel shows text; JTextField accepts typed input; and JButton triggers an action. A layout manager determines component placement. An action listener runs when a user clicks a button.

2.2 Build a greeting application

Save the complete program below as GreetingApp.java. The SwingUtilities.invokeLater call starts the GUI on Swing's event dispatch thread.

import javax.swing.*;
import java.awt.*;

public class GreetingApp {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(GreetingApp::createWindow);
    }

    private static void createWindow() {
        JFrame frame = new JFrame("Student Greeting App");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        JPanel panel = new JPanel(new GridLayout(3, 1, 8, 8));
        panel.setBorder(BorderFactory.createEmptyBorder(20, 20, 20, 20));

        JTextField nameField = new JTextField();
        JButton greetButton = new JButton("Greet Student");
        JLabel resultLabel = new JLabel("Enter your name above.");

        greetButton.addActionListener(event -> {
            String name = nameField.getText().trim();
            if (name.isEmpty()) {
                resultLabel.setText("Please enter your name.");
            } else {
                resultLabel.setText("Welcome, " + name + "!");
            }
        });

        panel.add(nameField);
        panel.add(greetButton);
        panel.add(resultLabel);
        frame.add(panel);
        frame.setSize(420, 220);
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);
    }
}

Run javac GreetingApp.java and java GreetingApp on a computer with a desktop graphical environment. Type your name and click the button. The label should display a personalized greeting. A headless server or text-only online compiler may not support desktop windows.

2.3 Extend the GUI: adding numbers

This second example demonstrates input conversion and error handling. Save as AdditionApp.java.

import javax.swing.*;
import java.awt.*;

public class AdditionApp {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Addition Calculator");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel panel = new JPanel(new GridLayout(4, 1, 8, 8));
            panel.setBorder(BorderFactory.createEmptyBorder(15, 15, 15, 15));

            JTextField first = new JTextField();
            JTextField second = new JTextField();
            JButton add = new JButton("Add Numbers");
            JLabel result = new JLabel("Result appears here");

            add.addActionListener(event -> {
                try {
                    double a = Double.parseDouble(first.getText().trim());
                    double b = Double.parseDouble(second.getText().trim());
                    result.setText("Total: " + (a + b));
                } catch (NumberFormatException ex) {
                    result.setText("Enter two valid numbers.");
                }
            });

            panel.add(first);
            panel.add(second);
            panel.add(add);
            panel.add(result);
            frame.add(panel);
            frame.setSize(360, 260);
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);
        });
    }
}

3.1 Spring vs. Spring Boot

The Spring Framework provides tools for building Java applications, including dependency injection and web development. Spring Boot builds on Spring by simplifying configuration, managing dependencies through starters, and supporting embedded web servers. A REST API allows clients to request data over HTTP, often receiving JSON.

3.2 Generate your project

  1. Visit start.spring.io.
  2. Select Maven, Java, and a stable Spring Boot version compatible with your installed JDK. For this lesson, use Java 17 or later and verify the version requirements shown by Initializr.
  3. Set Group to com.example and Artifact to studentapi.
  4. Add the Spring Web dependency (in newer versions this may be labeled Spring Web MVC).
  5. Click Generate, unzip the project, and open it in your IDE as a Maven project.

The project will contain pom.xml for dependencies, src/main/java for Java source, and src/main/resources/application.properties for configuration.

3.3 Create your first REST controller

In the package com.example.studentapi, create GreetingController.java:

package com.example.studentapi;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import java.util.Map;

@RestController
public class GreetingController {

    @GetMapping("/api/greeting")
    public Map<String, String> greeting(
            @RequestParam(defaultValue = "Student") String name) {
        return Map.of("message", "Welcome, " + name + "!");
    }
}

@RestController marks the class as a web controller. @GetMapping connects a URL to a method. @RequestParam reads a value from the URL query string. Returning a map produces a JSON response when the Spring web JSON converter is available through the web starter.

3.4 Run and test

Keep the generated StudentapiApplication.java main class in the same base package. From the project directory, run:

# macOS / Linux
./mvnw spring-boot:run

# Windows PowerShell

Visit http://localhost:8080/api/greeting?name=Alex on the computer running your app. Expected JSON:

3.5 Add a second API endpoint

Create CourseController.java in the same package. This endpoint returns a sample course record.

package com.example.studentapi;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;
import java.util.Map;

@RestController
public class CourseController {

    @GetMapping("/api/course")
    public Map<String, Object> course() {
        return Map.of(
            "code", "CMPS",
            "title", "Introduction to Java",
            "lessons", 3,
            "active", true
        );
    }
}

Restart if necessary and visit http://localhost:8080/api/course. Explain why JSON contains quoted strings, a numeric value, and a boolean value.

Common troubleshooting

Java command not found

Confirm the JDK is installed and its bin directory is on your system PATH. Restart your terminal and check java -version.

Public class name does not match file

For public class GreetingApp, save the file as GreetingApp.java with matching capitalization.

Swing window does not appear

Run on a desktop environment with graphical support. A remote or headless environment may not be able to display a Swing window.

Spring Boot port 8080 already in use

Stop the other service or add server.port=8081 to src/main/resources/application.properties, restart, and use port 8081 in the URLs.

Spring endpoint returns 404

Check the endpoint path and HTTP method. Make sure controller classes are in the main application's package or a subpackage, and confirm the server started successfully.
